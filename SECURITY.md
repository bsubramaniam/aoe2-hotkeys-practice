# Security Policy

## Reporting a vulnerability

Please use the repository's **Security** page and select **Report a
vulnerability** to submit a private report. Do not include private user files
or publish exploit details in a public issue before the report has been
reviewed.

Include the affected page or component, reproduction steps, expected impact,
and any suggested mitigation. Reports concerning the current `main` branch or
the hosted prototype are in scope.

General bugs and feature requests that do not contain sensitive security
details may be filed as public GitHub issues.
